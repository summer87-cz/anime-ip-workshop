# 动漫IP形象工坊 · Anime IP Workshop

> 把一张照片、一个玩偶、一个吉祥物，或者一句人设，做成一套**可长期复用的动漫 IP 形象档案**——不是一张插图，而是能一直往下用的角色资产。

一个 AI Agent Skill（技能包）。给它一份人设，它产出角色档案、形象图、三视图、表情包，还能延伸到 3D 手办与生活周边效果图。

---

## 它解决什么问题

做过 AI 形象的人都遇到过这几件事：

- 第一张图很满意，第二张脸就变了，第三张连眼镜都换了。
- 想做成表情包，结果 8 张图看起来像 8 个人。
- 换个画风重做，头身比跟着乱，前后两张摆一起不像同一个角色。

这个 skill 把这些问题拆成可执行的约束：**先建档案锁定身份锚点 → 出一张确认图 → 用三视图作为一致性闸门 → 再逐张派生表情与场景**。每一步都有具体的提示词模板和质检项。

## 快速开始

### 1. 准备出图通道

本 skill **不含任何出图实现**，也不绑定任何平台。你只需要两个能力，配置成命令模板：

```bash
export T2I_CMD='your-t2i-cli --prompt "{prompt}" --size {size} --out {outdir}'
export I2I_CMD='your-i2i-cli --prompt "{prompt}" --ref "{ref}" --size {size} --out {outdir}'
```

**硬要求：通道必须支持图生图（带参考图输入）**。三视图和表情包的一致性完全建立在"每次都以上一张已确认的图作参考"之上，纯文生图做不到。

用 HTTP API 的话，看 [`adapters/README.md`](adapters/README.md) 里的接口契约与请求示例。

### 2. 开始用

```
调用 动漫IP形象工坊，把这张照片做成我的动漫 IP 形象。
```

或者直接读 `SKILL.md` 按流程走。

## 核心设计原则

这个 skill 的价值不在"能出图"，而在**把出图翻车的地方变成了可复用的约束**。几个例子：

**比例不是越大越好，也不是越小越好。** 2.5 头身会显得头大不协调，3.5-4 头身最自然。但缩小头部有个副作用：**脸会被拉尖**。所以比例句后面必须紧跟"`<参考图脸型>`、`<下颌特征>`、不要锥子脸"。

**"简洁"不能只写"简洁"。** 只写这两个字，模型会自行往冷暗调跑。必须拆成四项：主色数量、明度、元素配额、禁止杂色清单。

**造型反复调不准时，别再堆文字。** 文字改了四次都不对的发型，换成"把用户给的截图直接当参考图、写'直接复制参考图的头发'"，一次就对了。

**表情包必须粗描边。** 表情包最终会被缩到 100-220px 用在聊天里，细线条一缩小就糊，只有粗描边撑得住轮廓。

**画面里的屏幕一律熄屏。** 亮屏会让模型乱填内容，出来的全是乱码。

更多实操细节见 `SKILL.md` 与 `references/prompt-recipes.md` 的"常见翻车自救表"。

## 已知限制（诚实说明）

- **三视图阶段脸型会漂**：模型倾向于把参考图的脸型画瘦、画尖，必须逐条写死约束。已在文档中标注，但无法保证 100% 一次成功。
- **表情包 8 张仍会有轻微漂移**：眉毛浓淡、眼镜宽窄、背景色偏白是最常见的三类，需要每张重述全部锚点，并逐张验收。
- **周边与手办的一致性弱于表情包**：14 条周边模板已全量实测（14/14 出图成功，产品感全部成立），但角色在这些图里会被"重新演绎"——**脸变瘦、发型毛刺感消失、眼镜变细**。修法（把可验证特征逐条写进锁定句）已写入 `references/merch-and-figures.md`。
- **手指仍是薄弱环节**：精细手势（张五指、抓握、托举）容易崩，文档里给了"手部安全清单"。
- **画风库除简约扁平外，其余风格的难度评级为"待实测"**，属经验推断，不做实测承诺。
- **不负责下游工序**：配图排版、表情包加文字、头像裁剪、动态化，需接其他工作流。

## 隐私与肖像权（重要）

- **本仓库不含任何真人照片、用户素材或生成成品。** 示例图请自备。
- 本 skill 处理的是**真人的面部信息**。使用时请注意：
  - 只用你自己拥有或已获授权的照片；
  - 生成的 IP 形象若用于**商业用途**（带货、广告、付费产品、周边售卖），需取得肖像权人授权，建议留存书面确认；
  - 不要把他人照片连同生成结果一并公开。
- `.gitignore` 已默认忽略 `ip-profiles/`、`photos/`、`*.heic` 等目录——**误提交真人照片不可逆**，请勿删除这些规则。
- 文档中的发型、脸型、配饰、服装、场景等具体描述均为**虚构示例**，不对应任何真人；实际使用时必须以用户提供的参考图为准。
