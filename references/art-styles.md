# 画风库 · IP 形象专用（v0.1 草案）

> 用途：给「动漫IP形象工坊」提供可选画风清单 + 可直接粘贴的提示词模板。
> 出图通道：图生图走 `I2I_CMD`，文生图走 `T2I_CMD`（占位符见 `adapters/README.md`）。
> 写作说明：**除 S1 有本 skill 的实操记录外，其余难度评级均为基于模型行为的预估，标注「待实测」**；首次使用后回填真实翻车记录，不要当成已验证数据。

---

## 0. 选画风的判断标准

### 0.1 一句话分界：插画风靠"这一张好看"，IP 风靠"第一百张还认得出"

一张图好看，往往靠的是环境、光影、氛围、笔触、颗粒这些**只在这一张里成立**的东西；而一个 IP 形象要活下来的，是**能重复的形状**——剪影、固有色、五官规则、线条性格、比例。这两套东西经常互相打架：

- 让画面"高级"的词（氛围光、复杂环境、材质颗粒、厚涂笔触），几乎全部落在**小尺寸会消失**或者**每次生成都不同**的位置上；
- 让 IP "立得住"的词（粗轮廓、纯色块、固定瞳色、固定发束分组），几乎全部是**减法**。

所以判断一种画风能不能当 IP 主画风，不看它单张多美，看它**删掉氛围之后还立不立得住**。

### 0.2 五个可操作测试（选风格前逐条过）

| # | 测试 | 做法 | 不合格的信号 |
|---|---|---|---|
| 1 | **缩略图测试** | 把图缩到 100px 左右看（微信列表/表情面板的实际尺寸） | 五官糊成一团、只剩一坨颜色 |
| 2 | **剪影测试** | 把角色填成纯黑，只看外形 | 认不出是谁、和别的角色剪影撞 |
| 3 | **八表情测试** | 同一画风下能否画出 8 个可区分的表情 | 委屈/困惑/思考/惊讶四个区分不出来 |
| 4 | **八连张测试** | 同风格连出 8 张，看颜色/线宽/脸型漂不漂 | 每张都"稍微有点不一样"，摆一起像换了个人 |
| 5 | **延展测试** | 改一处细节要不要重画全图；能不能接三视图、贴图、视频 | 一改就得重做整个场景 |

**实际排序：**通过 1/2/3 的才配当表情包画风；通过 4/5 的才配当长期 IP 画风；只通过"单张好看"的，归到"场景皮肤"里去，别当主画风。

### 0.3 铁律：一条提示词只能有一个"材质方向"，不许混

这是对比多份中文提示词教程后最有用的一条结论：风格词决定"像什么"，材质词决定"摸起来像什么"。**同方向叠加 = 质感增强；跨方向乱叠 = 材质打架**（模型不知道该保留干净线稿还是让笔触吞掉线条，结果两头不靠、画面发脏）。

常见冲突组合（写之前自查）：

| 冲突 A | 冲突 B | 后果 |
|---|---|---|
| 干净数码线稿 `clean lineart` | 粗糙手绘线 `rough lineart` | 线条半糊半利，像描歪了 |
| 赛璐璐硬阴影 `cel shading` | 柔和混色 `soft blending` | 变成半厚涂，赛璐璐味全丢 |
| 扁平色块 `flat colors` | 厚涂笔触 `rich brush strokes` | 色块里长出脏笔触 |
| 水彩晕染 `watercolor washes` | 硬边阴影 `hard shadows` | 又湿又硬，像发霉 |
| 精修抛光 `polished rendering` | 重颗粒 | 干净的东西被撒了灰 |

**本库每个风格 = 一套固定的材质栈**，切换风格等于换整套，不是加形容词。

### 0.4 在 skill 里的使用规则

1. 用**风格 id**（S1-S10）选定，一旦选定，整个流程（首图→三视图→8 张表情）**冻结同一个 id**，中途不换。
2. 换风格 = 新建 `vN-<风格名>/` 目录重跑，不在同一批里混。
3. 同一 IP 允许「**1 个主画风 + 最多 2 个场景皮肤**」（皮肤只用于节日图/封面/周边，不用于三视图和表情包）。
4. 每个模板已内置该风格的头身比，**会覆盖 SKILL.md 里"3.5-4 头身"的默认值**，见附录 A。

## S1 简约扁平手绘 · Flat Vector Hand-drawn Anime

**视觉特征**
- 线条：粗黑等宽描边，线宽全图统一，转角圆钝，轮廓闭合、不抖动、不加笔锋。
- 上色：平涂纯色块，一块颜色只有一个色值，色块之间**不渐变**，最多加一层比底色深 10% 的硬边暗部。
- 光影：柔和平光，接近无方向；不画投影，只在地面留一片极淡的接触阴影。
- 质感：无材质、无纹理、无颗粒，表面像刚印刷出来的矢量图。

**适合**：几乎所有个人 IP、知识博主、企业官号、课程头像。性格偏"温和、克制、专业、耐用"。缺点是"高级感"有限，做奢侈品/高端品牌会显得轻。

**提示词模板**（直接粘进 `图生图通道` 的编辑指令位）

```text
把这张照片转换成简约扁平手绘动漫角色：粗黑等宽描边轮廓线，线宽全图统一，转角圆钝，轮廓闭合不抖动；上色为扁平纯色块，一块颜色只有一个色值，色块之间没有渐变，只有一层比底色略深的硬边暗部；柔和平光，不画方向性阴影，只在脚下留一片极淡的接触阴影；表面无任何材质纹理和颗粒。保留人物的脸型特征、<发型>、<眼镜>、<神态>，完整全身包含腿和鞋，纯暖米白背景，角色居中占画面高度约八成五，身体只轻微侧转十到十五度接近正面，头部正视镜头。全身约三点五头身，头部高度约占全身四分之一，脖子略加长，肩膀略宽，不要再是大头小身。脸型必须与参考图一致：`<脸型描述>`，`<下颌线特征>`，绝对不要尖下巴和锥子脸。

反向：不要 3D 渲染，不要写实质感，不要照片感，不要厚涂光影，不要渐变过渡，不要描边粗细不一，不要复杂背景，不要文字和标识，不要添加任何未提及的元素或道具。Avoid muddy shadows, speckles, dirty texture, cluttered background, over-sharpening, text, watermark.
```

**难度**：容易（**本库唯一有实操记录的风格**）。
**翻车点**（全部实测撞过，详见 SKILL.md）：
- 默认往 2.5 头身跑 → 头大身小；缩头又会让脸变尖 → 必须同步写"`<参考图脸型>` + `<下颌特征>`"。
- 手部最先崩 → 一律插兜/持物/搭台面，不画张开五指。
- 屏幕类元素会自己长出乱码 → 明写"熄屏纯深灰空白屏"。
- 一句话只写"简洁"会往冷暗调跑 → 拆成"主色≤4 + 高明度 + 元素配额 + 禁杂色"。

**是否进库**：**★推荐（默认主力）**。理由：唯一在 1024px 与 100px 两个尺寸都稳的风格；改一处不用重画；贴图、三视图、表情包全链路验证过。

## S2 日系赛璐璐 · Cel-shaded Anime（TV Animation Frame）

**视觉特征**
- 线条：细而干净的深色（不是纯黑，用深棕黑）线稿，线宽统一偏细，线条闭合、末端略收，不出现速写毛边。
- 上色：赛璐璐二分法——每块颜色只有"底色 + 一层硬边阴影"；阴影边界像剪纸一样锐利；头发按片分组，每组一个深色块；瞳孔两层同心色 + 一个白色圆形高光点。
- 光影：正面柔和主光，阴影形状明确、不含渐变；不写逆光、不写环境反射。
- 质感：完全无材质，皮肤不带一点纹理，靠"分色"而不是"过渡"塑造体积。

**适合**：个人 IP、二次元向创作者、游戏/动漫类账号、年轻受众品牌。性格偏"清爽、有精神、略有中二感"。做中年/商务人设会显轻浮。

**提示词模板**

```text
把这张照片转换成日系赛璐璐电视动画角色：细而干净的深棕黑线稿，线宽统一偏细，线条闭合、末端略收，没有速写毛边；上色为赛璐璐二分法，每一块颜色只有一个底色加一层硬边阴影，阴影边界像剪纸一样锐利干净，绝对没有渐变和柔和过渡；瞳孔由两层同心色块加一个白色圆形高光点组成，高光边缘干脆；头发按大片分组上色，每组只有一个深色块，发梢略尖；皮肤只保留鼻下、下颌线、锁骨三处硬边阴影；柔和的正面主光，阴影形状明确，不写逆光。保留人物的脸型轮廓、<发型>、<眼镜>、<神态>。完整全身含鞋，纯浅米色背景，全身约四点五头身，身体侧转十到十五度接近正面，头部正视镜头。

反向：不要厚涂，不要笔触，不要柔和渐变，不要喷枪过渡，不要写实质感，不要照片感，不要 3D 渲染，不要霓虹光效，不要复杂背景，不要线宽忽粗忽细，不要多光源，不要文字。Avoid soft airbrush blending, painterly strokes, photorealistic skin, gradient shading, muddy shadows, text, watermark.
```

**难度**：中等（待实测）。
**翻车点**：
1. **写 cel shading 却出半厚涂**——模型默认把阴影做成软过渡。解法：正向必须出现"只有一层阴影 + 边界像剪纸一样硬"，反向必须点名"不要喷枪过渡"。
2. **瞳色变渐变**——眼睛是最容易被"美化"的地方，会自己加高光晕。解法：写死"两层同心色 + 一个圆点高光"，并把高光数量限定为一个。
3. **头发被画成写实发丝**——赛璐璐要求"片状分组"。解法：写"按大片分组、每组只有一个深色块"，反向加"不要单根发丝"。
4. **4.5 头身对表情包偏写实**——如果 IP 主要用来做表情包，把头身比压到 4 头身，眼睛放大约 15%，否则缩到 100px 时表情全糊。

**是否进库**：**★推荐（第二主力）**。理由：形状语言比扁平丰富得多（发型、服装、眼神都有表现力），仍然靠纯色块，缩略图可读；是"想好看又不想脏"的最优解。

## S3 Q 版厚涂 · Chibi Painterly（Soft Impasto）

**视觉特征**
- 线条：**不描线或极淡的暖色线**，靠色块交界和笔触方向区分结构。
- 上色：脸部保持干净平涂（这是硬规矩），厚涂只出现在头发分组、衣服褶皱、道具上；颜色在同一色相内做深浅，不做彩虹。
- 光影：单一方向柔和主光 + 一层暖色反光，只在头发和衣服上做体积，脸部不加深阴影。
- 质感：哑光颜料，可见笔触堆叠和干笔触的破碎边缘，像画在厚纸上的丙烯。

**适合**：封面主视觉、公众号头图、课程宣传图、需要"高级感 + 可爱"的品牌。性格偏"温暖、有质感、略文艺"。**不适合**当表情包主力——笔触在 100px 会糊成噪点。

**提示词模板**

```text
把这张照片转换成 Q 版厚涂动漫角色：约三头身，头部明显偏大，头高约占全身三分之一，身体圆润短小、四肢短粗，手掌简化成圆润的块状、不画手指；脸部保持干净平涂色块，五官简洁——大眼、小鼻点、一条嘴线，脸部绝对不要笔触和厚涂肌理；厚涂笔触只出现在头发分组、衣服褶皱和道具上，可见颜料堆叠的方向性笔触，边缘为干笔触的轻微破碎感；单一方向的柔和主光加一层暖色反光，只在头发和衣服上做体积，脸部不加阴影；整体为哑光颜料质感，不要油亮反光。保留人物的脸型特征、<发型>、<眼镜>、<神态>。完整全身，纯暖灰背景，身体略侧转接近正面。

反向：不要写实皮肤，不要毛孔，不要油光，不要塑料感，不要 3D 渲染，不要照片感，不要多层渐变，不要脸部出现脏笔触，不要复杂背景，不要彩色光效，不要文字。Avoid oily highlights, photoreal texture, dirty blending, cluttered background, airbrush gradients, text, watermark.
```

**难度**：困难（待实测）。这是本库里最容易"出脏图"的风格。
**翻车点**：
1. **脸被笔触吃掉**——厚涂一旦上脸，五官立刻糊。解法：正向明确"脸部干净平涂 + 绝对不要笔触"，这是本风格的第一优先级约束。
2. **颜色发灰**——厚涂爱在暗部堆中间灰调。解法：限定"同一色相内做深浅"，反向加"不要灰调、不要脏混色"。
3. **头身比和主流程冲突**——3 头身与 SKILL.md 的 3.5-4 头身铁律相反，必须显式覆盖，否则两张图摆一起像两个角色。
4. **表情包不适用**——笔触在小尺寸变噪点，8 张并排会花。用这个风格就别做表情包，或者接受"表情包另出一版 S1/S2"。

**是否进库**：**推荐，但限定用途（主视觉/封面）**。理由：单张质感天花板最高，一致性成本和脏图风险也最高；放在"封面皮"而不是"档案皮"最划算。

## S4 3D 皮克斯/迪士尼风 · Stylized 3D Animation

**视觉特征**
- 线条：无描边，靠形体转折和明暗交界表现结构；轮廓线完全由光影"长"出来。
- 上色：柔和的大色块 + 连续的明暗过渡（这是唯一允许渐变的主画风），颜色饱和但不刺眼。
- 光影：三点柔光（斜上主光 + 补暗辅光 + 只勾一侧的轮廓光），阴影边缘柔和，接触阴影清晰。
- 质感：哑光次表面散射皮肤（像硅胶不像塑料）、整块片状发束、布料褶皱少而圆润。

**适合**：品牌吉祥物、儿童/教育、消费品牌官号、需要"亲切 + 可信"的形象。性格偏"友好、无害、国际化"。做硬核/潮流/先锋品牌会显幼稚。

**提示词模板**

```text
把这张照片转换成 3D 动画电影角色：圆润概括的形体，头部略大于真人比例、脸颊饱满、下巴圆；眼睛为大而明亮的椭圆，虹膜有清晰的同心圆结构和一个柔和的方形高光；头发做成整块的片状发束，不追求单根发丝；皮肤为柔和的哑光次表面散射质感，颜色均匀、没有毛孔和油光；服装为简洁的整块布料，褶皱少而圆润；三点柔光布光——主光在斜上方、辅光补暗部、轮廓光只勾一侧边缘；背景为从中间向四周过渡到纯色的浅灰摄影棚背景，人物脚下有柔和的接触阴影。保留人物的脸型特征、<发型>、<眼镜>、<神态>。完整全身约三点五头身，身体侧转十到十五度接近正面。

反向：不要写实皮肤毛孔，不要恐怖谷真人脸，不要写实布料纤维，不要金属反光，不要暗调背景，不要体积雾，不要粒子光斑，不要镜头光晕，不要背景道具，不要文字。Avoid photoreal human skin, uncanny valley, gritty texture, harsh shadows, dark moody lighting, lens flare, text, watermark.
```

**难度**：容易（待实测）——因为 GPT Image 系**默认就往 3D 跑**，这条几乎不用"拉"，只要"收"。
**翻车点**：
1. **过写实变恐怖谷**——不写"哑光、圆润、无毛孔"就会滑向真人渲染。这三个词是本风格的锚。
2. **塑料感**——高光太硬太多。解法：写"哑光"，反向写"不要油光、不要塑料反光"。
3. **一致性中等**——3D 材质细节多，同角色两次生成的高光位置、发束分块会变。做表情包时要靠三视图死死锚住，并接受"每张要人工过目"。
4. **小尺寸反而稳**——形体大、颜色整，100px 可读性比厚涂好，这是它的优势。

**是否进库**：**推荐（头像/吉祥物向）**。理由：出图门槛最低、亲和力最强、缩略图可读；代价是一致性靠参考图硬撑，且风格"通用感"强、辨识度不如手绘。

## S5 美式漫画线条 · American Comic Ink

**视觉特征**
- 线条：可变粗细的墨线，外轮廓最粗、内部结构线较细，收笔有尖峰，带手绘的不均匀感。
- 上色：平涂大色块 + 一层硬边暗部，暗部用**排线和规则网点**填充，网点只在中灰区，不覆盖脸。
- 光影：硬光，阴影形状明确、边缘锐利，允许强烈明暗对比（但用"明确的形状"而不是"压暗"来做）。
- 质感：干净米白漫画纸，颗粒极淡几乎不可见。

**适合**：运动/健身、潮流服饰、硬核测评、男性向个人 IP、需要"力量感 + 态度"的品牌。性格偏"硬、直、有点痞"。

**提示词模板**

```text
把这张照片转换成美式漫画角色：可变粗细的手绘墨线勾边，外轮廓最粗、内部结构线较细，线条有收笔的尖峰和不均匀的手感；上色为大块平涂加一层硬边暗部，暗部用排线和规则网点填充，网点为均匀规则的点阵、只出现在阴影和衣服暗面，绝对不覆盖脸部五官；五官结构强化——明确的眉弓、略方的下颌、眼白清晰、瞳孔小而实心；硬光照明，阴影形状明确、边缘锐利；纸张为干净的米白漫画纸，表面干净。保留人物的脸型特征、<发型>、<眼镜>、<神态>。完整全身含鞋，纯米白背景，全身约五头身，身体略侧转接近正面，头部正视镜头。

反向：不要厚涂，不要柔和渐变，不要写实光影，不要 3D 渲染，不要彩色光晕，不要脏噪点，不要网点糊在脸上，不要对话框和文字，不要添加未提及的元素或道具。Avoid soft shading, muddy halftone, dirty texture, photoreal rendering, gradient glow, text, watermark.
```

**难度**：困难（待实测）。
**翻车点**：
1. **网点被当成噪点**——这是本风格最大的坑：模型把 halftone 理解成"撒颗粒"，整张图变脏。解法：写"均匀规则的点阵 + 只在中灰区 + 不覆盖脸"，反向点名"不要脏噪点"。
2. **线条变潦草**——"可变粗细"容易被理解成"乱"。解法：加"外轮廓最粗、内部结构线较细"的层级说明。
3. **脸部结构被强化过头**——眉弓、下颌一狠就显凶、显老，人脸相似度掉得厉害。做真人改图时把"略方的下颌"降级为"保留原脸型"。
4. **和扁平风混用**——同一 IP 里出现粗墨线 + 扁平色块会像"两种画风拼接"。要么全上，要么不用。

**是否进库**：**慎用（条件推荐）**。理由：风格辨识度极高，但只对"硬/潮/运动"人设成立；对普通个人 IP 会把气质带偏，且脏图率高、脸部相似度损失大。

## S6 水墨 · Chinese Ink Wash

**视觉特征**
- 线条：**必须有墨线**。水墨做角色造型时，结构完全靠线条交代（水墨没有明暗可依，眉弓鼻梁眼睑只能靠线），线条有提按、有干湿、有起收笔。
- 上色：只用三档墨色——焦墨（头发、眉眼、衣领暗部）、中墨（衣服主体）、淡墨（皮肤阴影、远景），三档之间是干净色阶，不做无限过渡。
- 光影：无光源概念，靠"墨的浓淡 + 留白"暗示体积；不画投影。
- 质感：宣纸纤维，纸面干净；墨色边缘有极轻微的渗化，但**不能渗到五官**。

**适合**：国风/传统文化/茶/书法/中医/东方美学类 IP 的**封面图、节日图、周边、片头**。作为主画风见下节评估。

**提示词模板**（已按"线描为骨 + 墨色为肉"设计，不要用纯写意版本）

```text
把这张照片转换成水墨线描角色：以干湿变化的墨线勾勒全部轮廓与结构——脸型、下颌、眉眼、发际线、衣纹、手指都先用墨线交代清楚，线条有起笔重、收笔轻的提按变化；墨色只用三档——焦墨用于头发、眉眼、衣领暗部，中墨用于衣服主体，淡墨用于皮肤阴影和远景，三档之间是干净色阶、不做无限过渡；皮肤基本留白，只在鼻侧、下颌、颈部各加一笔淡墨；瞳孔用浓墨点出、眼白完全留白，保证眼神可读；背景大面积留白，只在一角用两笔淡墨示意环境；宣纸质感，纸面干净无脏污。保留人物的脸型轮廓、<发型>、<神态>。完整全身，约四点五头身，身体正面略侧。

反向：不要彩色，不要水彩晕染糊住脸，不要写实光影，不要 3D 渲染，不要渐变色块，不要泼墨飞白盖住五官，不要墨色发灰发脏，不要背景堆满山水，不要印章和书法文字，不要添加未提及的元素。Avoid muddy ink wash, blurred facial features, grey dirty tone, photoreal rendering, heavy paint splatter, text, seal stamp.
```

**难度**：困难（待实测）。
**翻车点**：
1. **五官被墨晕吃掉**——最致命。哪怕写了"淡墨"，模型仍会在脸的暗部堆墨。解法：正向把"五官用墨线交代"放在句首（权重最高位），并把"眼白完全留白"写死。
2. **整张发灰**——水墨天然落在中灰区间，一旦没有焦墨锚点，就变成"洗淡了的黑白照"。解法：给"焦墨三处"具体指派（头发/眉眼/衣领）。
3. **三视图的背面无解**——背面没有五官和衣领这些墨色锚点，模型会画成一张"水墨山水背影"。做三视图时建议背面单独加"只勾轮廓 + 一片中墨衣背 + 留白"的说明。
4. **小尺寸消失**——见下节。

**是否进库**：**不推荐作为主画风，推荐作为"场景皮肤"**（详见下节）。

### S6.1 深度评估：水墨到底能不能做 IP 形象？

**结论：不能当主画风，能当二级皮肤。**理由分五条，从强到弱：

1. **它的"好看"落在小尺寸必消失的地方。**水墨的美感来自墨色浓淡的连续变化和渗化边缘——这两样在 100px 缩略图里全部糊成一片中灰。这是有外部实证的：一位水墨表情包作者（《光明日报》2020 年报道）明确写过，在宽高仅 240px 的表情图里"呈现清晰可见的水墨风显然不行"，她最终的处理是"尽量保留一些自然笔触，和卡通漫画风格进行融合"。**真正上架过水墨表情包的人，最后做的也是混合**，不是纯水墨。

2. **它撑不住 8 个表情的区分度。**表情包 8 张里，"委屈、困惑、思考、惊讶"这四个主要靠眉眼的细微形变和嘴角方向来区分；水墨写意天然省略鼻梁、眼睑、嘴角这些结构，笔触的"宽容"恰好把这些差别抹平。网上那些"想画清冷美人结果画成搞笑表情包"的翻车，本质都是同一件事：**水墨擅长气韵，不擅长微表情**。

3. **一致性最差。**水墨的随机渗化正是它的价值所在，也意味着同一角色画两次墨边一定不同；而 IP 的第一要求是"第一百张还认得出"。这一条和 IP 的定义正面冲突，不是靠提示词能压住的。

4. **动态化成本最高。**表情包动图 12–24 帧，逐帧墨色浓淡不连续会闪；且透明底表情包**没有"宣纸留白"**——一导出就是白底上的一块灰，和平台白底撞在一起，边界全无。

5. **行业侧的风险提示也对得上。**2026 年上半年国漫水墨热的观察里，被点名的三个隐忧是：风格空心化（只套一层水墨滤镜）、同质化（一窝蜂"千篇一律的黑白灰"）、为风格牺牲可读性（动作看不清、表情不到位）。这三条恰好就是"水墨做 IP"会踩的三个坑。

**那它该怎么用才不浪费？**

- 定位：**二级皮肤**。只用于节日图、封面、周边、片头、知识卡片配图，不进入三视图和表情包环节。
- 技法：必须走"**线描为骨 + 墨色为肉**"的混合路子（水墨动画的通行做法就是给主要形体加轮廓线，因为水墨无法靠明暗分辨结构）。S6 模板已内置这个处理。
- 尺寸门槛：输出不小于 1024px，且不要裁切成方形小图。
- 心理预期：接受"它是一个插画 IP，不是一个表情包 IP"。如果用户要的就是水墨主角 + 表情包，正确做法是**双轨**：S6 做形象主视觉，S2 或 S1 做表情包，两者共用同一套身份锚点。

## S7 绘本水彩 · Picture-book Watercolor

**视觉特征**
- 线条：细而柔和的墨褐色勾线，线条不完全闭合，留有呼吸的断口，末端略淡。
- 上色：高透明度薄涂，每块颜色由浅到深叠加不超过三层；颜色边缘自然晕开一小圈，但五官和轮廓线始终清晰。
- 光影：无明确光源，均匀柔和天光；阴影只用一层淡冷灰蓝薄涂。
- 质感：冷压水彩纸纹理，纸面干净，可见极淡的颜料沉淀边。

**适合**：儿童/亲子、女性向、心理/疗愈、读书/写作类 IP。性格偏"温柔、慢、有故事感"。做科技/金融/硬核内容会显弱。

**提示词模板**

```text
把这张照片转换成儿童绘本水彩角色：先用细而柔和的墨褐色线勾出五官与身体轮廓，线条不完全闭合、留有呼吸的断口；上色为透明度高的水彩薄涂，每一块颜色由浅到深叠加不超过三层，颜色边缘自然晕开一小圈，但五官和轮廓线始终保持清晰、绝对不被晕开；腮红、耳尖、指尖加一点偏暖的湿画法红晕；没有明确光源，整体是均匀柔和的自然天光，阴影只用一层极淡的冷灰蓝薄涂；冷压水彩纸质感，纸面干净。保留人物的脸型特征、<发型>、<眼镜>、<神态>。完整全身，约三点五头身，纯米白背景，画面四周留白。

```

**难度**：中等（待实测）。
**翻车点**：
1. **五官被晕开**——水彩最典型的失败：眼睛变成两团墨。解法：句首写"先勾线、线不被晕开"，反向点名"不要五官被晕开"。
2. **只加一层滤镜**——只写"水彩"会得到"低饱和数码图"。必须同时出现三件事：颜料（薄涂叠加）、边缘（渗化）、纸张（冷压纸纹）。
3. **颜色发灰**——薄涂叠多了就是灰。解法：限定"不超过三层"。
4. **表情包慎用**——晕染边缘在 100px 会糊，8 张并排偏"软"。头像和封面没问题。

**是否进库**：**推荐（儿童/疗愈向）**。理由：这个赛道的标准画风，情绪价值高；只要守住"线不被晕"就能用，且纸纹不影响缩略图识别。

4. **表情包不适用**——底座、高光、哑光反射在 100px 全部变成脏点。

**是否进库**：**推荐（周边/带货向）**。理由：这是"能卖货"的画风，实体化想象直接、商业转化好；但只适合周边和主视觉，不适合档案日常图。

## S9 儿童蜡笔手绘 · Crayon Kids Drawing

## S10 羊毛毡/黏土手作 · Felt & Clay Handcraft

**视觉特征**
- 线条：无描边，边缘是柔软的绒毛扩散轮廓，不是硬边。
- 上色：纤维染色形成的柔和色块，颜色之间有细微的纤维交织过渡，不是纯色块。
- 光影：柔和正面散射光，无强高光，阴影极浅。
- 质感：细密长绒毛 + 针脚缝线，关节与衣服接缝处露出一两处缝线。

**适合**：玩偶/手作/生活方式类 IP、实体玩偶周边、需要"手工温度"的小众品牌。性格偏"软、暖、慢"。

**提示词模板**

```text
把这张照片转换成羊毛毡玩偶角色：整体由羊毛毡纤维构成，表面是细密柔软的长绒毛，边缘呈柔软的绒毛扩散轮廓而不是硬边；头部圆润、四肢短粗，针脚和缝线只在关节与衣服接缝处露出一两处；五官用缝制方式表现——黑色小圆珠做眼睛、一小块粉色毡片做腮红、一条深色缝线做嘴；头发为一片整体毡化的发块，表面有顺向的纤维纹理；服装为毡片缝制，边缘有微微起球的毛边；柔和的正面散射光，没有强高光，阴影极浅。保留人物的脸型轮廓、<发型>、<神态>。完整全身约三头身，正面站立，纯米白背景，脚下有极淡的接触阴影。

反向：不要塑料，不要 3D 渲染的平滑曲面，不要金属反光，不要写实布料，不要一根根写实的毛发，不要脏污绒毛，不要暗调，不要复杂背景，不要文字。Avoid smooth plastic surface, glossy 3D render, photoreal fur strands, dirty fuzz, dark lighting, text, watermark.
```

**难度**：困难（待实测）。
**翻车点**：
1. **绒毛变写实毛发**——写"毛"就会被理解成动物毛。解法：写"羊毛毡纤维 + 绒毛扩散轮廓"，反向点名"不要一根根写实的毛发"。
2. **一致性最差**——毛毡纹理每次随机，两次生成像两个手作师傅做的。做表情包必须先有三视图，且接受重跑率高。
3. **小尺寸糊**——绒毛边缘在 100px 会糊成一团。只适合大图、周边、封面。
4. **"黏土"和"毛毡"不能混写**——一个光滑一个毛糙，同句出现会出"长毛的塑料人"。

**是否进库**：**慎用**。理由：情绪价值独特、实体化最直接，但一致性最差、尺寸要求最高，只建议在用户明确要"手作玩偶感"时用。

## 附录 B：跨风格通用件

### B1. 一致性句（任何风格，接在指令末尾）

```text
以参考图中的角色为同一个 IP，严格保持脸型、五官、发型分块、服装、配饰、颜色锚点和线条性格一致，只改变本张的表情、动作和（可选）道具；头身比与本系列其他图完全一致。
```

### B2. 反向通用尾串（每条都带）

```text
不要 3D 渲染（S4 除外），不要照片感，不要复杂背景，不要文字和标识，不要水印，不要添加任何未提及的元素或道具。
Avoid muddy shadows, speckles, dirty texture, cluttered background, over-sharpening, text, watermark.
```

### B3. ⛔ 禁词区（**只能出现在反向里，绝不能出现在正向描述中**）

以下词会把画面拖向"脏、糊、噪点"，写前逐条自查：

`film grain` · `Kodak Portra` · `cinematic lighting` · `cinematic color grading` · `dramatic lighting` · `volumetric fog` · `glowing particles` · `high contrast` · `neon glow` · `peeling paint` · `steam` · `wet asphalt reflections` · `ultra detailed` · `hyper detailed background`

**替代写法**：想要"高级"→ 写"干净的固有色 + 明确的形状"；想要"氛围"→ 写"柔和平光 + 大面积留白"；想要"质感"→ 写"哑光/磨砂"这类**单向材质词**，不写"颗粒/雾/光效"。

### B4. 交付前风格自查（5 条）

- [ ] 整批图是同一个风格 id，没有中途换栈？
- [ ] 头身比符合附录 A 的该风格值？
- [ ] 100px 缩略图还认得出脸？
- [ ] 反向串里"不要文字/不要添加未提及元素"都在？
- [ ] 正向里没有混入两个冲突的材质方向（见 0.3）？
