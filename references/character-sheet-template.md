# IP DNA 模板

为新的照片、玩偶、吉祥物、宠物、物件或人设描述创建可复用 IP 档案时，使用本模板起草 `IP_DNA.md`。

档案的目的：让这个角色在**未来所有生成图里保持稳定**——哪些特征必须一致、哪些可以变化、哪些绝对不能出现。

## 档案结构

```markdown
# <IP 名称> IP DNA

本文件是 <角色名> 的唯一权威档案，所有下游生图必须遵守。

## 基础信息

- 档案编号: <日期-角色名>
- 主角色:
- 来源类型: 照片 / 玩偶 / 头像 / 吉祥物 / 宠物 / 物件 / 纯文字人设
- 来源完整度: 全身 / 大半身 / 半身 / 头像 / 局部
- 角色定位: <IP 主理人分身 / 品牌吉祥物 / 故事角色 / 表情包主角>
- 目标画风: 简约动漫扁平风（默认）/ 其他（用户指定）
- 出图路线: 文生图（`T2I_CMD`）+ 参考图改图（`I2I_CMD`，尺寸 1024x1536）

## 身份锚点（必须逐字锁定）

- 整体轮廓: <如：圆胖梨形 / 高瘦长条>
- 头部形状 / 发型: <具体到颜色、长度、刘海形状>
- 脸部节奏: <脸型、腮红、雀斑等>
- 眼睛规则: <如：两点眼 / 豆豆眼带高光 / 圆眼双眼皮>
- 眉毛规则:
- 嘴巴规则:
- 标志性配饰: <如：黑框眼镜、红色围巾——辨识度核心，绝不漂移>
- 服装: <上装 / 下装 / 图案>
- 下半身: <可见则写实描述；不可见写"保守推断：……">
- 鞋子 / 底部结构: <同上>
- 身体比例: <如：二头身 Q 版 / 五头身>
- 颜色锚点: <3-5 个主色，给具体色名>

## 简化规则

- 删除的照片细节: <皮肤纹理、真实光影、碎发、布料褶皱……>
- 扁平化处理: <复杂图案→简单形状>
- 最高细节密度: <如：全身不超过 7 个视觉元素>

## 表情与动作范围

- 允许的情绪: <8 张表情包的组合在此规划>
- 常用道具: <与角色定位相关的标志道具>
- 禁止姿势: <如：不出现写实手指特写>

## 提示词胶囊

<一段 80-150 字的中文提示词，包含全部锁定特征 + 画风 + 负向项。每次生图直接粘贴在提示词开头。>

## 负向规则（每条提示词末尾附加）

- 不要 3D 渲染、写实质感、照片感、厚涂光影
- 不要添加任何未提及的元素或道具
- 不要 <本角色专属禁忌，如：不改变发型颜色>

## 质检清单

- [ ] 身份锚点逐项对照通过
- [ ] 眼睛/脸部规则无漂移
- [ ] 服装与配饰稳定
- [ ] 比例与轮廓与三视图一致
- [ ] 背景色与既有图一致
```

## 起草纪律

1. 锚点必须**具体可见**："可爱""聪明""高级"这类抽象词禁止单独出现，必须翻译成画面决定（如"聪明"→"眼镜 + 托腮思考姿势"）。
2. 看不清或有多解的特征标 `未知`，给 1-2 个保守选项让用户选。
3. 半身/头像源的下半身标 `保守推断`，并在交付说明里列为待确认项。
4. 风格 DNA 与角色 DNA 分离：线条、纸纹等共享风格属于下游工作流；角色独有特征才进本档案。
5. 用户每修正一个锚点，**先更新本档案再生成后续图**，保证档案永远是最新事实。
