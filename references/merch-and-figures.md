# 周边与手办（3D 手办化 + 生活周边 DIY）

> 用途：拿到已确认的 IP 形象（三视图 / 全身确认图）之后，把角色落到实物上出**产品效果图**。
> 出图通道：走图生图适配器 `I2I_CMD`，占位符 `"{prompt}" "{ref}" {size} {outdir}`（见 `adapters/README.md`）。
> 尺寸：手办方图 `1024x1024`；手办 + 包装盒场景用横版 `1536x1024`；周边单件平铺/挂拍用 `1024x1024`；周边场景连拍用横版。
> 标注「待实测」的条目是推演出来的写法，未经真实出图验证，不要当成已验证结论。

## 零、开工前必须记住的五件事

### 1. 「产品感三件套」缺一件，模型就往插画跑

一张图要让人相信"这是实物照片"，靠的不是形容词，是三个具体锚点：

| 锚点 | 作用 | 写法示例 |
|---|---|---|
| **尺寸锚点** | 让模型知道这东西有多大 | "高约 8 厘米""1/6 比例""11 盎司容量""230 克精梳棉" |
| **承托物** | 有底座 / 有桌面 / 有包装盒，才是商品 | "浅米色圆形薄底座""放在浅木色桌面上""旁边立着彩盒" |
| **摄影规格** | 定机位、定光、定背景 | "无缝纯白背景 + 顶部柔光箱 + 左右补光板 + 30 度俯视" |

只写"把角色做成手办"，出来的必然是 3D 渲染插画：没有底座、没有接触阴影、没有背景，一眼假。

### 2. 2D 转 3D 要锁「识别特征」，不能锁「扁平画风」

这是最容易搞错的一条。

- **做手办时**：参考图是扁平动漫插画，成品必须是立体物件，画风必然变。所以要锁的是**脸型轮廓、五官比例与位置、眼睛形状与瞳色、发型结构与发流、发色、标志性配件、服装配色与图案分布**——这些不变，脸就不会跑。
- **做印花周边时**（T恤、贴纸、帆布包）：反过来，图案必须**保持扁平矢量感**，明令"不要 3D 渲染、不要立体光影、不要厚涂"。印花是平面印刷，一旦图案本身有立体光影，印到布上就是一团糊。

一句话：**手办锁特征转立体，印花锁扁平禁立体。**

### 3. 别"把角色贴上去"

Miora 那套 IP 全案的实战记录里踩过两个坑，都很典型：

- 做颈枕时**漏掉了企鹅的红围巾**，整个 IP 一致性当场断掉 → 周边必须写清"必须保留的识别物清单"，一件都不能少。
- 红绳手柄、普通白圆柱底座这类细节一出现就显廉价 → 底座和配件要写形状、颜色、圆角，不要留给模型自由发挥。

真正像商品的周边，是**图案按产品曲面透视变形、印刷边缘与表面完全贴合、不留浮起阴影**。不写这一句，图案会像贴纸浮在杯子上。

### 4. 禁词与替代词（写前逐条核）

| 禁用（必糊必脏） | 换成 |
|---|---|
| film grain / 颗粒感 | 细腻均匀的表面（哑光/釉面按材质写） |
| cinematic lighting / dramatic lighting | soft diffused studio lighting（柔和均匀棚拍光） |
| neon glow / 发光 | 柔和高光、局部反光 |
| volumetric fog / 烟雾 | 干净的空气感、无烟雾 |
| ultra detailed / hyper detailed | 主体边缘干净、结构清晰、背景极简 |
| high contrast / HDR | 明暗过渡柔和、暗部不压死 |
| gritty texture / 做旧 | 只在需要时写"轻微使用痕迹"，其余写"表面洁净" |

**细节分布铁律**：只让产品主体精细，背景一律极简。写"主体清晰精细 + 背景无缝纯色、无杂物"，不要写"细节丰富"。

### 5. 别写品牌名

- "iPhone 手机壳" → 写"手机壳"（背面单摄像头开孔 / 三摄开孔按需说明即可，不写型号）
- "星巴克杯" → 写"陶瓷马克杯"
- "泡泡玛特风" → 提示词正文写"潮玩盲盒 / 设计师玩具收藏品风格"，品牌名只留在内部沟通里，不写进提示词
- 产品上不要出现任何 logo、价格签、条形码、可读文字（除用户明确要求的角色名，且要短）

### 1. 潮玩盲盒（设计师玩具感）

**视觉特征**：3.5 头身、头略大于身、四肢圆润短小；**哑光 PVC 软胶**，几乎不反光，只在肩、鼻尖、膝盖有柔和高光；工厂喷绘上色，色块边界干净、无溢色；五官靠印刷贴花，眼神清亮但**不发光**；整体是"设计过的小玩具"，不是"缩小版真人"。

**尺寸感与底座**：实高约 8 厘米，**异形主题底座**（云朵形、草地片形、不规则圆台），直径略宽于肩宽，边缘圆角。底座千万别写成"白色圆柱"——那是 Miora 实测被用户点名的廉价感来源。

**可复制提示词**

```
保持参考图中角色的面部识别特征完全一致：脸型轮廓、五官比例与位置、眼睛形状与瞳色、发型结构与发流走向、发色、<角色标志性配件，如红色围巾/黑色方框眼镜/发夹>、服装配色与图案分布，全部沿用；这是同一个角色的立体化，不是重新设计，不要换脸、不要换发型、不要改服装配色。
把该角色做成一只高约 8 厘米的潮玩盲盒收藏手办：约 3.5 头身，头略大于身体但比例协调，四肢圆润短小，手指简化为三指圆头，不追求写实解剖。
材质：哑光 PVC 软胶，表面细腻均匀、不反光不发油，仅在肩膀、鼻尖、膝盖三处有柔和的高光；上色为工厂喷绘，色块边界干净利落，无色差无溢色，衣服图案与参考图一致，五官为印刷贴花，眼睛清亮有神但不要发光。
姿态：<双手捧着一只小杯子站在底座上 / 单腿微抬像是要迈步 / 坐姿双腿自然垂在底座边缘>，重心稳定，与底座接触处有自然的受力感，不要悬浮。
底座：<淡米白色云朵形薄底座 / 浅草绿色不规则草地片底座 / 浅灰色圆角圆台>，底座直径略宽于角色肩宽，边缘做圆角，底座正面完全留白，不要任何文字和图案。
构图：3/4 侧前方、约 30 度俯视机位，产品完整入画并居中，占画面高度约七成五，四周留出充足空白。
摄影：无缝纯白背景，顶部一盏大面积柔光箱加左右各一块白色补光板，光线均匀柔和、明暗过渡平缓；产品底部有淡淡的接触阴影让它在台面上站住；主体从上到下全幅清晰，背景仅极轻微虚化，不要大面积虚化到看不清产品边缘。
不要添加任何未提及的元素或道具，不要出现文字、logo、价格标签、条形码、人物手指、卡通描边线、厚涂笔触、二次元高光加闪。
Avoid film grain, dirty texture, muddy shadows, harsh glow, neon lighting, cluttered background, over-sharpening, watermark.
```

**翻车点**

| 症状 | 根因 | 修法 |
|---|---|---|
| 出成 3D 渲染的角色立绘 | 没有底座、没有接触阴影、没有摄影规格 | 补齐"三件套"，尤其写"底部接触阴影" |
| 脸变成通用萌脸，不像本人 | 只写"保持面部一致"，没给可验证的特征 | 写到"眼睛形状 + 瞳色 + 眼距"，别用抽象词 |
| 一排手办像复制粘贴 | 一次生成多只 | **一只一张**，姿态和底座逐只写不同，禁止写"六款一套" |
| 底座是个白圆柱，显廉价 | 没规定底座形状 | 指定异形底座 + 圆角 + 直径关系 |
| 手办飘在画面上方 | 没写接触关系 | 写"与底座接触处有自然受力感，不要悬浮" |
| 全身油光像塑料雨衣 | 哑光没写死 | "哑光、不反光不发油 + 只在三处柔和高光" |

### 2. 粘土 / 软陶手办

**视觉特征**：手感第一。表面有**细腻的手工压痕和极轻微的不平整**，边缘不是刀切般的锐利而是圆钝的，颜色有轻微的厚薄不均（像颜料刷上去的），眼睛是两粒小圆点或画上去的，服装褶皱是"捏出来"的圆弧而不是布料的尖折。整体暖调、拙、可爱。

**尺寸感与底座**：实高约 10-12 厘米，通常放在**浅木色圆片底座**上或直接坐在桌面，不做复杂底座（手工感物件配精致底座会打架）。

**可复制提示词**

```
保持参考图中角色的面部识别特征完全一致：脸型轮廓、五官比例与位置、眼睛形状与瞳色、发型轮廓与发色、<角色标志性配件>、服装配色，全部沿用；这是把同一个角色捏成软陶手办，不是重新设计角色。
把该角色做成一尊高约 11 厘米的手工软陶手办，整体带有明显的"人手捏出来"的特征：表面是细腻的哑光陶土质感，有轻微的按压痕迹和极淡的指纹感，但整体洁净不脏；所有边缘圆钝、没有刀切般的锐边；颜色为手工上色，带轻微的厚薄不均和一点点笔触过渡，不是喷绘那种绝对均匀的色块。
五官：眼睛为手工点画的两粒小圆点或上挑的眼睛形状，眼神温和；嘴巴简单一条弧线；头发由一片片压扁的陶土拼接而成，能看到拼接处的轻微起伏，不要一根根发丝。
姿态：<坐着，双腿自然垂在桌面边缘 / 站着，双手在身前轻轻交叠>，姿态放松、有一点笨拙的可爱，重心稳定。
底座：浅木色圆形薄木片底座，直径略大于角色肩宽，木纹清晰、边缘圆润，底座上不要任何文字。
构图：3/4 侧前方、约 25 度俯视机位，产品完整居中，占画面高度约七成，四周留白。
摄影：浅米白色无缝背景，左侧一扇大窗透进柔和漫射的自然光、右侧用白色反光板补光，光线温暖均匀；产品底部有淡淡的柔和阴影；主体全幅清晰，背景仅极轻微虚化。
不要添加任何未提及的元素或道具，不要出现文字、logo、手指、工具、泥土碎屑、卡通描边线。
Avoid film grain, gritty texture, dirty surface, muddy shadows, harsh contrast, cluttered background, over-sharpening, watermark.
```

**翻车点**

- **想用 film grain 造假手工感 → 直接糊**。手工感要靠"压痕 + 圆钝边缘 + 上色不均"三个实体特征写出来，不靠颗粒。
- 指痕写太多变"脏" → 加定语"轻微的、极淡的，整体洁净不脏"。
- 变成塑料感 → 一定要写"哑光陶土""不是喷绘那种绝对均匀"。
- 头发被做成一缕缕发丝 → 明写"一片片压扁的陶土拼接，不要一根根发丝"。

### 3. 树脂精细手办（收藏级）

**视觉特征**：这是最像"真商品"的一类，也是**最容易翻车成真人**的一类。比例 1/6-1/7，实高 24-28 厘米；皮肤上色有细腻渐变，唇部、指尖、耳廓带一点血色；衣物褶皱锐利有厚度；**透明亚克力圆形底座 + 旁边立一只带角色图的彩盒**，是所有爆款图的同一套公式。

**尺寸感与底座**：1/7 比例、高约 25 厘米，**透明亚克力圆形底座（无文字）**，底座厚度 1 厘米左右、边缘有透明的厚度反光。

**可复制提示词**

```
保持参考图中角色的面部识别特征完全一致：脸型轮廓、五官比例与位置、眼睛形状与瞳色、发型结构与发流走向、发色、<角色标志性配件>、服装配色与剪裁，全部沿用；这是同一个角色的高精度立体化，不要换脸、不要写实化成另一个真人。
面部必须保持动漫化结构：眼型、眼距、瞳色与参考图一致，脸型是动漫比例而不是真人骨骼，绝对不要真人皮肤毛孔、不要真人唇纹、不要写实皱纹；只在鼻尖、颧骨、唇部有一点点自然的立体起伏。
把该角色做成一尊 1/7 比例、高约 25 厘米的收藏级树脂手办：整体为细腻的树脂材质，皮肤上色是柔和的渐变，带一点点通透感，唇部与指尖有极淡的血色；服装褶皱锐利、有真实厚度和利落的转折，金属配件有细腻的金属反光，布料与皮革在反光上明显区分。
姿态：<微微侧身回头、一只手抬起靠近肩部 / 单手扶帽檐、重心落在后腿>，动态自然、有故事感，重心稳定。
底座：圆形透明亚克力厚底座，直径略大于角色肩宽，底座侧面能看到透明亚克力的厚度与边缘反光，底座上不要任何文字和铭牌。
环境：产品立在浅木色桌面上，右后方立着一只彩盒，盒子正面印着同一个角色的插画、侧面为纯色加极简几何图形，盒面为哑光覆膜、局部有轻微光泽；彩盒完整入画，不要被裁切。
构图：略低于视平线的机位、平视偏上约 10 度，产品与彩盒一起构成画面主体，占画面宽度约七成，四周留白。
摄影：浅灰白色无缝背景，主光为左前方大面积柔光箱，右侧一块白色反光板压住暗部，产品背后有一道极淡的轮廓光把边缘从背景里分出来；产品从头顶到脚底全幅清晰，背景极轻微虚化；桌面有柔和的接触阴影。
不要添加任何未提及的元素或道具，不要出现任何可读文字、logo、价格标签、条形码、包装上的乱码字样。
Avoid film grain, dirty texture, muddy shadows, harsh glow, neon lighting, cluttered background, over-sharpening, watermark.
```

**翻车点**

| 症状 | 根因 | 修法 |
|---|---|---|
| **脸变真人 / 变网红脸** | "写实""精细"这类词把动漫脸推向真人 | 明写"保持动漫化结构 + 不要真人毛孔唇纹"，再加"脸型是动漫比例不是真人骨骼" |
| 皮肤像塑料假人 | 只写"树脂"，没写上色 | 补"柔和渐变 + 通透感 + 唇部和指尖极淡血色" |
| 彩盒上的图案和角色对不上 | 盒子只写了"印角色图" | 写"印着同一个角色、发型与服装与主体完全一致" |
| 彩盒上的文字变乱码 | 让模型自己编品牌名 | 写"盒面不要可读文字，只用极简几何图形" |
| 底座玻璃感太强像水晶 | 只写"透明" | 写"透明亚克力，侧面有厚度与边缘反光" |

### 4. 毛绒 / 布偶化

**视觉特征**：不是手办，但同类需求、且极受欢迎。核心是**"布"的证据**：短毛绒面料的绒毛方向感、缝合线、填充后的鼓包、下垂的重量感、眼睛和嘴是刺绣而非塑料件、侧面缝一只小布标。

**尺寸感与底座**：实高约 25 厘米坐姿，**不需要底座**，坐在浅色平面或靠着什么。

**可复制提示词**


## 第三块 · 选型与工作流

### 1. 什么形象适合做什么（省掉一半试错）

| 形象特征 | 优先推荐 | 原因 |
|---|---|---|
| 头大身小、五官简洁 | 盲盒手办、贴纸、亚克力立牌 | 造型越简越像成品玩具，细节少不易糊 |
| 细节多、服装复杂 | 树脂收藏手办 | 只有这个规格撑得住复杂褶皱和配件 |
| 配色柔和、线条圆润 | 毛绒玩偶、抱枕 | 圆润造型适合布艺，硬细节会被布吃掉 |
| 图案笔画少、色块大 | T 恤、帆布包、马克杯 | 丝网/热转印只有 1-3 色才印得清 |
| 有强识别小配件（围巾、眼镜、发夹） | 全部品类 | **每张图都必须点名这件配件**，漏了就断 IP |

### 2. 命令行与尺寸

```bash
# 单只手办（方图）
"$I2I_CMD" "<手办提示词>" "<三视图/全身图>" 1024x1024 "<目录>" -o "<目录>"

# 手办 + 包装盒场景（横版，右侧留位给盒子）
"$I2I_CMD" "<树脂手办提示词>" "<全身图>" 1536x1024 "<目录>"

# 周边单件平铺 / 挂拍（方图够用）
"$I2I_CMD" "<周边提示词>" "<全身图>" 1024x1024 "<目录>"
```

- 参考图一律用**竖版全身图**，别用方图头像：头像补全身会导致比例失控（skill 内已实测）。
- 改图约 60-70 秒/张，属正常，不要误判卡死。
- 一次只做一件。想凑"一套周边"，逐件生成后再拼版，**不要让模型一图出多件**——必然出现风格漂移和风格混搭。

### 3. 交付前自检（每条都过一遍）

1. **它知道自己是一张产品照吗？** 画面里有没有底座/桌面/包装盒？有没有接触阴影？有没有明确机位和光源？
2. **尺寸写了吗？** 厘米、比例、盎司、克重，至少一个。
3. **图案是印上去的还是浮上去的？** 有没有"完全贴合、无浮起阴影、无胶膜反光"？周边图案有没有"随曲面透视变形"？
4. **一致性锁住了吗？** 开头有没有锁脸/锁发型/锁配色？有没有点名那件标志性配件？
5. **禁词清了吗？** film grain / cinematic lighting / neon glow / volumetric fog / ultra detailed / high contrast 全无。
6. **有商标风险吗？** 有没有 iPhone、星巴克、泡泡玛特、任何 logo 和可读文字？
7. **图案出血了吗？** 图案有没有被画框/开孔/缝线切断？四边留白够不够？
8. **2D/3D 方向对吗？** 手办要立体（有厚度、有材质、有高光位置）；印花要扁平（不要 3D 渲染、不要厚涂）。

### 4. 实测记录（2026-10-22 全量跑通，14/14 成功）

**测试条件**：单张全身参考图（有场景背景）→ 逐条模板 → 方图 1024×1024 → GPT Image 2.5，每张 33-70 秒。

**结果：14 条模板全部可用，产品感全部成立。** 没有一条出成"3D 渲染角色立绘"或"画贴在产品上的插图"——说明"产品感三件套（尺寸锚点 + 承托物 + 摄影规格）"这套写法是有效的。

| 类别 | 结果 | 备注 |
|---|---|---|
| 潮玩盲盒 | ⭐ 最佳 | 哑光质感、异形底座、3.5 头身，最像真商品 |
| 粘土/软陶 | ⭐ 优秀 | 手工质感与坐姿自然，木质圆台很加分 |
| 树脂精细手办 | ✅ 良好 | 亚克力底座 + 旁边彩盒很专业；**但人物被拉成 4+ 头身偏瘦高**，不像手办比例 |
| 毛绒/布偶 | ✅ 良好 | 绒感与圆润度到位；脸偏小眼偏大属毛绒化必然 |
| 手机壳 / T恤 / 马克杯 / 帆布包 / 抱枕 / 徽章 / 立牌 / 保温杯 | ⭐ 优秀 | 产品形态、材质、图案贴合全部准确，无明显翻车 |
| 钥匙扣/亚克力挂件 | ⭐ 优秀 | 3mm 透明厚度 + 白边 + 金属扣，辨识度极高 |
| 贴纸套装 | ✅ 良好 | 6 枚模切排布正确；**模型自行给每枚贴纸换了不同姿态**（对贴纸套装是加分，但一致性会偏离） |

**唯一共性问题：角色识别度漂移（14 张全部出现）**

产品图里的角色被"重新演绎"了一遍——衣服配色（深灰衬衫+白T+黑裤）保住了，但：

- **脸变瘦变长**，`<参考图脸型>` 变成偏瘦尖脸；
- **发型毛刺感消失**，变成普通短寸；
- **眼镜变细变圆**，不再是矩形细边全框。

原因：周边阶段要求"把 2D 角色转译成 3D 实物或印花图案"，模型会按产品类型重新塑形，**"保持面部一致"这句话的约束力弱于表情包阶段**（表情包是同维度转译，周边是跨维度转译）。

**修法（已写入模板，用前务必加上）**：

1. 锁定句里不要只写"保持面部识别特征"，要**把可验证的具体特征写出来**：
   > 脸型与参考图一致：`<脸型描述>`、`<脸颊特征>`、`<下颌线特征>`、`<下巴形状>`，绝对不要瘦长脸；眉毛 `<参考图眉毛特征>`；`<参考图眼镜/配饰款式>`，不要改变形状；发型 `<参考图发型描述>`，保留 `<参考图发丝质感>`，不要变光滑平顺。
2. **参考图优先用单人的正面全身图**，不要用三视图整张（三个人物会让模型混淆）。
3. 做**手办类**时额外写："保持约 3.5 头身，头略大于身，不要拉成真实人体比例"——否则模型会把手办做成瘦高模特。
4. 做**印花类**（手机壳/T恤/杯/包）时额外写："图案保持扁平矢量风格，不要 3D 光影，图案随产品曲面自然透视变形"。

**其余遗留观察**：
- 帆布包的"清晰经纬织纹"实测**没有吃掉图案细节**，强度可接受，不必降级。
- 保温杯的"哑光喷涂 + 单道竖向高光"**成功压住了不锈钢强反光**，图案完整可见。
- 徽章的"弧形反光"没有盖住脸，可用。
- 亚克力立牌的"插接缝隙 + 底座透光"表现正常，没有被画成浑浊透明块。

> 也就是说：原先列的 5 条"待实测"**全部通过**，可以去掉待验证标记。
