# 提示词配方库（可复制模板）

> 全部模板实测有效。`<尖括号>` 按 `IP_DNA.md` 替换。拼装顺序：**前缀（锁锚点）→ 本张差异项 → 后缀（画质/配色/风格）**。

---

## 一、通用前缀（每次必带）

### A. 锁面部与头部

```
保持参考图中角色的面部特征完全不变：脸型必须与参考图一致：`<脸型描述>`、`<下颌线特征>`、`<脸部饱满度>`，绝对不要尖下巴和锥子脸，五官、`<标志性配饰>`、`<发型描述>`、`<神态>` 严格一致，不要重新设计脸和发型。
```

### B. 锁比例（3.5-4 头身）

```
比例：全身约 3.5 头身，头部高度约占全身高度四分之一，脖子略加长，肩膀略宽，身体略修长，头身比例协调自然，不要再是大头小身。
```

### C. 锁视角（正面略侧 10-15 度）

```
视角：身体只轻微侧转约十到十五度接近正面，胸口和脸基本朝向镜头，头部正视镜头，绝对不要大角度四分之三侧转、不要侧身、不要回头看。
```

### D. 头发标准描述（按用户参考图替换，不对应任何真人）

```
发型：`<发色>`、`<长度>`、`<覆盖范围>`；发际线 `<高度>`，边缘 `<整齐/参差>`；两侧渐变带 `<宽度>`；头顶外轮廓 `<短毛立起的毛刺锯齿/平滑弧线>`，`<单根长度>`，整体贴着头骨、不隆起、无厚度。

> 以上为写法示例，不对应任何真人；实际使用时必须按用户提供的参考图替换。
绝对不要：光滑平整的发块、像扣了黑色壳子、锅盖头、蘑菇头、一圈齐整黑边、发丝变长分离、碎发外翘、头顶隆起、尖顶、飞机头、刺猬头、刘海。
```

### E. 只改一处时（局部修改铁律）

```
只修改<部位>，画面其他所有内容严格保持不变：构图、人脸、五官、眼镜、表情、服装、手表、姿态、<场景元素清单>、背景全部原样不动，画框里的画内容也不要改动。
```

## 二、通用后缀

### 画质

```
清晰高解析度，柔和明亮均匀光线，边缘锐利，低视觉噪点。不要 3D 渲染，不要写实质感，不要照片感，不要厚涂光影，不要文字和 logo，不要添加任何未提及的元素或道具。Avoid film grain, muddy shadows, speckles, gritty texture, cluttered background, harsh glow, over-sharpening, text, watermark.
```

### 配色克制（四要素）

```
配色克制：全画面只有白、浅灰、浅米、浅木、<主色>以及一点<点缀色>点缀，不要紫红橙黄杂色，不要花哨，不要高饱和大色块。整体为高明度浅色调，画面通透明亮，不要暗调背景，不要阴影过重。
```

### 扁平动漫风

```
简约扁平手绘动漫插画，粗黑描边轮廓线，扁平色块无渐变。
```

## 三、场景模板

### 1. 明亮咖啡馆（咖啡馆吧台）

```
场景：明亮通透的独立咖啡馆，浅米白色墙面，左侧带白色细窗框的大窗、窗外柔和虚化浅色街景，深胡桃木整体柜体吧台，台面上一台打开的笔记本电脑处于熄屏状态为纯深灰空白屏、不显示任何内容不发光，左前方地面一盆落地绿植（深灰陶盆），窗台一小盆矮绿植，人物右侧墙上挂一幅完整的横幅雪山风景画带深胡桃木窄边框，墙面留白处安静悬浮一只浅灰色小型方块机器人（浅灰机身深灰描边、两只小青色圆点眼睛、头顶短天线、不要动态线不要发光），地面浅灰白。画面中不要任何桌椅组合。
```

### 2. 极简书房

```
场景：温馨的极简书房，浅暖灰色墙面，浅木色书桌配一盏造型简洁的台灯和几本摞起来的书，身后一排简化线条的木质书架，左侧一扇窗户透进柔和自然光，地面浅木色，书架顶层一盆小绿植。
```

### 3. 公园户外

```
场景：明亮晴朗的公园，浅绿色草坪，背景几株简化线条的大树，淡蓝色天空配几朵极简白云，浅灰色步道，柔和均匀的白天自然光；角色右上方空中悬浮一个小型半透明青色几何圆环，作为唯一的 AI 元素不要更多；画面干净不要密集树木不要杂乱细节。
```

### 4. 城市街头

```
场景：明亮通透的现代城市街区，浅灰白建筑外墙，几株简化线条的行道树，远处建筑轮廓浅色虚化，人行道浅灰色，柔和明亮自然光；空中小型半透明青色几何方块由细线连接，作为唯一 AI 元素；不要密集招牌不要文字。
```

### 5. 赛博实验室（暗调版）

```
场景：深灰蓝色纯色墙面，白色简洁实验台，台面上一个极简线条的三角烧瓶和一个白色方盒，墙面一道柔和的青色横向纯色光带（扁平色块不要光晕），空中悬浮一个半透明青色几何数据球和两个小方块由细线连接，地面深灰色；只此一处光带与一组悬浮物，其余留白，不要密集设备不要屏幕墙不要杂乱线缆不要光环刻度线。
```

### 6. 赛博实验室（明亮版，用户嫌暗时用）

```
场景：高明度浅色调的简洁未来实验室，浅灰白色墙面，纯白色简洁实验台，台面上极简线条的三角烧瓶与方盒，墙面中部一道柔和的青绿色横向纯色光带（扁平色块不要光晕），空中悬浮一个半透明青色几何数据球和两个小方块由细线连接，地面浅灰白带极淡反光，通透明亮大面积留白。
```

### 7. 白板讲解（教师/知识博主）

```
场景：明亮的极简教室，身后一整块带边框的白色白板，白板上用极简黑色细线条绘制<分子结构式：两个六边形苯环由化学键连接、外侧短线标注 O 和 N>，白板下方露出浅灰色讲台边缘，地面浅灰；除元素符号外白板上不要出现任何其他文字、数字或标题。
```

## 四、构图模板

### 全身（占高 85%）

```
构图：完整全身，从头到脚完整可见含鞋子，人物居中占画面高度约八成五，头顶上方留少量空白。
```

### 大半身（占高 90%，头顶到大腿中部）

```
构图：大半身，取景从头顶到大腿中部，人物居中成为画面主体，占画面高度约九成。
```

### 七分身（占高 95%，头像首选）

```
构图：镜头拉近，取景从头顶到膝盖上方，人物成为画面绝对主体占画面高度约九成五，头顶上方留少量空白。
```

### 半身胸像（方形头像）

```
构图：正方形半身胸像，取景范围从头顶到胸口，人物成为画面主体并占据画面主要面积，头部位于画面上部居中，头顶上方留出约百分之十五的空白，肩膀完整入画。
```

### 竖版扩成正方形（真正的左右扩图）

```
在参考图基础上修改，输出正方形构图，画面向左右两侧扩展背景，保留原场景全部元素并自然延伸墙面、窗户与地面，人物保持居中且完整全身，头顶上方留出适当空白。
```

## 五、姿态模板

### 斜靠吧台（休闲，物理成立）

```
姿态：斜靠在一张厚重稳固的深胡桃木长条吧台旁，身体侧转约十五度接近正面，左手手肘自然搭在吧台桌面上支撑身体，右手端着白色咖啡杯停在胸前，双腿在脚踝处轻交叉，重心落在一条腿上，姿态悠闲放松。
桌子必须看起来结实到足以承受人体重量：整块厚实深胡桃木台面、厚度约五厘米、宽度进深大，下方是四条粗壮笔直实木桌腿或一整块木质柜体支撑；绝对不要细腿、不要单根圆盘底座、不要轻飘飘的高脚小圆桌。
```

### 行走

```
姿态：正在向画面右前方自然行走，右腿在前左腿在后呈自然跨步，身体侧转约二十五度，左臂随步伐自然摆动，头部转向镜头；右手<端外带纸杯>。
```

### 扶手站立

```
姿态：右手轻轻扶着<长椅靠背/栏杆>，左手自然垂在身侧，身体侧转约十五度，一条腿略微前伸重心落在后腿。
```

### 手部安全清单

- 可用：插兜 / 自然下垂手指放松 / 手持杯子平板书本 / 手肘搭台面 / 掌心向上托小物（要写"手指自然微屈不要抓握"）
- **禁用**：张开五指、精细抓握、复杂手势、指向性手指

## 六、常见翻车 · 自救表

| 症状 | 根因 | 修法 |
|---|---|---|
| 头偏大、不协调 | 默认 2.5 头身 | 加"3.5 头身 + 头部缩小"模板句 |
| 脸被拉尖（锥子脸） | 缩头连带副作用 | 加"`<参考图脸型>` + `<下颌特征>` + `<脸颊特征>` + 不要尖下巴" |
| 发型像光滑黑帽 | 缺毛发质感描述 | 加"头顶外轮廓由极短头发一根根立起形成毛刺锯齿" |
| 发型像刺猬/尖顶 | 碎发写过头 | 加"每根两三毫米 + 不要发丝变长分离 + 不要头顶隆起" |
| 锅盖头/蘑菇头 | 头顶轮廓太平滑 | 强调毛刺锯齿轮廓 + 黑发覆盖面积大 + 两侧渐变窄 |
| 文字怎么调都不对 | 描述无法表达 | **直接拿参考截图作 `-r`，写"直接复制参考图的<部位>"** |
| 画面冷暗 | 只写了"简洁" | 拆成"主色≤4 + 高明度 + 元素配额 + 禁杂色" |
| 画面空 | 元素少 | 补 3-5 件同色系极简元素，或镜头拉近到 95% |
| 笔记本像玩具 | 缺尺寸锚点 | 写"屏宽≈肩宽 2/3、符合 14 英寸比例" |
| 人靠桌子不成立 | 桌子太轻 | 换整体柜体/粗腿厚台面，写"不要细腿圆盘底座" |
| 胳膊压到桌上物件 | 未写分离 | 写"人物右移 + 与物件留出清晰空隙 + 不要接触" |
| 屏幕出现乱码内容 | 亮屏 | 写"熄屏纯深灰空白屏 + 不要显示任何内容" |
| 画框被画面裁切 | 近景构图 | 写"画框四边完整可见 + 右边留墙面空隙" |
| 手部结构糊 | 头部缩小后必崩 | 简化为插兜/持物/搭台面 |
| 一图多稿混在一起 | 脚本内部重试 | 逐张过目，好稿重命名，废稿移 `_备选/` |
